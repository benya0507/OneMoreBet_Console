# OneMoreBet_Console
Console based casino simulator application in **Java**. Contains chip management system, slot machine RNG logic and interactive menu system.

## Features
 - Playing a slot machine
 - Checking cash and chip balance
 - A chip store; converting chips to cash, and cash to chips

## How to run
1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Make sure you have JDK 17 or higher installed
4. Run Main.java

## Technologies used
- IntelliJ IDEA
- Java 26
